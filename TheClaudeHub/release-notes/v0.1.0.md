# TheClaudeHub 0.1.0

TheClaudeHub is a keyboard and screen reader friendly reader for Claude Code sessions. It lists
every session the Claude desktop app has open, shows each one as a conversation you can arrow
through, tells you when a session answers, and switches the desktop app to a session when you need
the real thing. It can also start sessions of its own, which you read and reply to entirely from
here. It runs on your existing Claude subscription and never uses an API key.

This is the first release, and a pre-release: it has been used with JAWS on one PC.

## What's new

Everything, since this is the first release:

- **One window, three parts, in Tab order:** the session list, the messages of the session you
  load, and the reply box. Shift+Tab goes back the same way, and the session list is always there.
- **The session list** reads each session's title, repo, state (needs you, working or idle) and
  when it was last active, with sessions that need you first. It refreshes itself without moving
  your place.
- **Enter on a session** loads it and moves you to its messages, newest last. Enter on a message
  opens its full text to read by line, word and character; Escape comes back to it.
- **Question cards, permission refusals and plans** read as words in the chat. Tool calls are
  hidden unless you ask for them (Ctrl+T).
- **Replies are announced** through JAWS, NVDA or a Windows voice, at the level you choose: the
  whole reply, a summary, or silent.
- **Open in Claude** (Ctrl+O) switches the Claude desktop app to the session.
- **Sessions of TheClaudeHub's own** (Ctrl+N): read and reply to them here, with Ctrl+Enter.
  Sessions the desktop app owns are read-only, so two programs never write to one session.
- **Automatic updates:** TheClaudeHub checks for a new version when it starts, and from Help,
  Check for Updates. It tells you when one is available and asks before installing it. Your
  sessions and settings are kept.

## Downloads

- **TheClaudeHub-theclaudehub-Setup.exe**: the installer. It installs for you only (no administrator
  rights), adds TheClaudeHub to the Start menu, and keeps it up to date.
- **TheClaudeHub-theclaudehub-Portable.zip**: the same app in a folder, for running without installing. The
  portable copy doesn't update itself.
- The `.nupkg` and the `releases.theclaudehub.json`, `assets.theclaudehub.json` and
  `RELEASES-theclaudehub` files are the update feed the installed app reads. You don't need
  to download them.

Both are signed by "kelly ford". Windows SmartScreen may still ask about a new download until the
publisher builds up reputation.

## Requirements

- Windows 10 or 11. The app is built for x64; Arm PCs run it under Windows's x64 emulation.
- **Claude Code installed with its native installer, and signed in** to a Claude subscription
  (the same login the Claude desktop app uses). TheClaudeHub reads the sessions Claude Code keeps
  on your PC and runs your own sessions through the `claude` command.
- For reading the desktop app's sessions, the Claude desktop app.

Read the [TheClaudeHub README](https://github.com/kellylford/TheWorkBench/tree/main/TheClaudeHub)
for the keyboard shortcuts and how it works.
